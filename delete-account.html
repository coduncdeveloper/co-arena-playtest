Delete Your Account

Last updated: October 9, 2026

Deleting an Oath Ascendant account removes its server progress and sign-in record when the backend confirms every step. Removed progress cannot be recovered. Guest play does not create an account; explicit feedback and crash diagnostics are separate from guest saves.

Delete in the game

  1. Sign in to the account you want to delete, then open Account and the Account tab.
  2. Optionally choose Clear saves and queued data linked to this account. This keeps guest saves, other accounts, shared or legacy progress, device settings and unrelated storage.
  3. Press Delete Account, then Confirm Delete Account. You can cancel before the second press.
  4. Read the result. A missing or invalid server receipt is an unconfirmed deletion, not success. If sign-in record deletion is incomplete, you stay signed in so you can retry. Contact support if a retry does not finish it. If local sign-out or device cleanup fails, the result explains that separately.

Before deletion, Export Profile & Runs downloads server profile and run summaries. Export Save in Settings creates a local save backup.

No longer have the game?

Email coduncdeveloper@gmail.com with the subject "Oath Ascendant account deletion request." Identify the account email, or the Steam account for Steam sign-in. Do not send a password, authentication ticket or payment details. Account ownership must be verified before deletion.

What the current deletion service removes

  • The public profile, signed-in run records, cloud player saves, linked identity record and account-linked usage events.
  • The authentication user when the database permits it. Authentication deletion also cascades to dependent account records such as cloud Champion archives and entitlements. If it is blocked, these remaining records require a retry or support follow-up.
  • Pending device usage events for the deleted account. Optional local cleanup removes provably account-owned campaign slots, account-specific Raid checkpoints and that account's queued submissions or report drafts. It does not claim to erase unowned shared saves.

What can remain

Steam deletion retains a re-entry block with Steam identifiers, synthetic email, former account ID and deletion date. Submitted feedback can remain after its account link is removed, including reporter name, report text and screenshot. Unlinked crash diagnostics and previously published competitive history can remain. The current code has no automatic expiry for those records; provider backups and operational logs need separate review. Contact support about retained personal information.

Guest, other-account, shared or legacy device progress and settings are preserved. Their ownership markers remain to prevent cross-account transfer. Delete Local Campaign Progress in Settings separately clears local campaign runs, history, profile and unlock progress, including guests. It keeps Raid/Champion saves and settings; platform storage controls can remove the remaining device data.

Timing

In-game requests return a backend result during the action. A partial or unconfirmed result is not a completed deletion. Email requests require ownership verification and support follow-up. The release retention schedule and support response commitment still require owner confirmation.
