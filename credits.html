Fonts

The interface is designed around the Cinzel, Cormorant Garamond, and Inter typefaces, with system fallbacks. The project includes these SIL Open Font License 1.1 texts:

  • Cinzel (@fontsource/cinzel) — OFL 1.1

Backend services

Supabase — authentication, profiles, run telemetry, account-deletion RPC, and leaderboard/database hosting for optional account features.

Technology

  • React, React Three Fiber, Drei, Three.js and related rendering libraries
  • Zustand, Framer Motion and Lucide React
  • Electron and Steamworks integration for desktop; Capacitor for Android and iOS
  • Vite, TypeScript, ESLint, and related tooling — build/development tooling

Remotion is present as development/video tooling, not part of the browser game runtime, and is used under its own license model.
