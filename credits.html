Game

Design, code, balance, QA, integration, art direction, and launch production: the Iron Oath project owner, with AI assistance.

Visual art is AI-generated and human-curated for Iron Oath — directed, evaluated, selected, cropped/resized where needed, and integrated by hand, with transparent AI disclosure and the appropriate generative-art tag where the store requires it.

Fonts

The interface is designed around the Cinzel, Cormorant Garamond, and Inter typefaces, each licensed under the SIL Open Font License 1.1. (The game build itself does not bundle the font binaries — the families are named in CSS with system fallbacks.) Authoritative license texts:
