Privacy Notice

Last updated: October 9, 2026

Oath Ascendant is developed by Team Fullsend. Accounts are optional where offline play is available. Guest campaign progress stays on the device. Feedback you choose to submit and automatic crash diagnostics can be sent even without an account.

Account and gameplay data

  • Email sign-in uses Supabase Auth. Steam sign-in uses a Steam authentication ticket verified through our backend, together with Steam identity and ownership information. The game does not receive your Steam password or payment details.
  • Account data includes an account ID, email where applicable, username, optional bio, avatar and equipped cosmetics.
  • Signed-in services store run summaries, account progression and Champion archives, achievements or cosmetic entitlements, competitive standings and related records. Profiles and leaderboards can display your chosen name, bio, avatar, run summaries and standing. Email is not shown on those public surfaces.
  • With Share usage and balance data enabled, signed-in play sends account-linked events: session and screen activity, run outcomes, reward choices and combat/balance summaries, with app/platform versions, timestamps and event/session IDs. These events are not anonymous. The setting is on by default; turning it off stops new collection and drops pending usage events on this device. Signed-out play does not queue usage or balance events.

Feedback and diagnostics

  • Submitting feedback sends the report title and text, reporter name, account ID if signed in, screen/platform/version and viewport. An attached screenshot is uploaded to private Supabase storage. The local report can also contain the signed-in email; that email field is not included in the report upload.
  • Automatic crash diagnostics can send error text, stack traces, browser/device user agent, current screen and a limited run snapshot (such as class, floor, health and deck size). This diagnostic path is separate from the usage-data setting. Error text, screenshots or feedback may contain personal information, so avoid including unnecessary personal details in reports.

Device storage and services

Device storage holds saves, settings, local progression, report drafts and pending uploads. Authentication sessions are persisted in browser/Electron storage or native Capacitor Preferences. Steam Cloud can mirror supported saves and settings through the desktop wrapper.

Supabase provides authentication, database/RPC services and report screenshot storage. Valve provides Steam identity, ownership verification and Steam Cloud. Android and iOS use Capacitor as the native wrapper; the platform stores have their own privacy notices. The app source does not currently integrate advertising or an external analytics SDK.

Retention and deletion limits

Account records remain until deleted. The in-game deletion service removes the profile, signed-in runs, cloud player saves, identity link and account-linked usage events, and attempts to remove the authentication user. Other account-dependent records are removed by database cascades when authentication deletion succeeds. A partial result must be retried or followed up with support.

Steam deletion retains a re-entry block record containing Steam identifiers, the synthetic Steam email, the former account ID and deletion date. Submitted feedback can remain with its account link removed, including the words, reporter name and screenshot; crash diagnostics and previously published competitive history can also remain. The current code does not configure automatic expiry for these retained records. Provider-side backups and operational logs require separate review. These limits are release review items; a final retention schedule has not yet been adopted.

Account-linked device cleanup preserves guest saves, other accounts, shared or legacy progress and settings. Ownership markers for retained shared progress remain on the device to prevent another account receiving that progress. Local campaign reset is a separate explicit action in Settings. Device storage controls can remove the app's remaining local data.

Export and requests

Export Profile & Runs in Account downloads your server profile and run summaries as JSON. It is not a complete export of every account table. Export Save in Settings makes a device save backup. For other account data, retained feedback or deletion follow-up, contact coduncdeveloper@gmail.com. See Account Deletion for the exact flow and limits.
